# Сургут: фикстуры импорта

Публичная геометрия из сохранённых ответов Яндекс Афиши, ранее исследованных
в проекте (`.shots/yandex-hallplan*.json`). Здесь оставлены только уровни,
ряды, места, контуры и цены, используемые преобразователем. Это исторические
снимки для регрессионной проверки, не актуальное наличие билетов.

| Файл | Нумерованных мест по rows[].seatCount |
|---|---:|
| surgu.json | 512 |
| neftyanik.json | 1073 |
| vavilon.json | 359 |
| filarmoniya.json | 872 |

Полная вместимость танцпола не следует из availableSeatCount. Восстановленные
координаты и цены требуют проверки организатором до публикации схемы.
