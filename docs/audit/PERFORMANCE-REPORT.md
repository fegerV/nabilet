# Отчёт по производительности

## 1. Что измерено

В этой ветке **не проводились** замеры времени загрузки, отрисовки, выделения, перемещения, масштабирования, сохранения и потребления памяти для схем на 500 / 2000 / 5000 / 10000 / 20000 мест.

Причины:
- в проекте нет готового стенда бенчмаркинга Konva-сцены;
- браузерное профилирование не запускалось;
- требование ТЗ — не заявлять показатели без фактических измерений.

Поэтому в этом документе нет таблиц «до/после» с вымышленными числами.

## 3. Что осталось открытым

- Полная перерисовка Konva-сцены при изменении выделения/состояния (`HallEditorPage.vue`).
- Разделение статических и динамических слоёв, инкрементальные обновления, батчинг.
- Пространственный индекс для выделения и hit-testing на 20k мест.
- Упрощённая отрисовка на малом масштабе, отключение невидимых элементов.
- Оптимизация истории undo/redo (снимки всей схемы) иdeep-наблюдателей Vue.
- Контроль утечек обработчиков/изображений.

## 4. Как проводить замеры

1. Подготовить детерминированные фикстуры на 500/2000/5000/10000/20000 мест и зафиксировать их в репозитории.
2. Измерять в одном браузере/окне, с прогретой сценой, минимум 5 прогонов, брать медиану и p95.
3. Метрики: время загрузки схемы, время первого кадра, время выделения одного/группы, время перетаскивания, время масштабирования, размер JS-кучи до/после 20 циклов.
4. Результаты записать в эту таблицу **до и после** каждого изменения; без этого любые утверждения о «стало быстрее» не принимаются.
