Статус: **не выполнена**. Документ — протокол для ответственного владельца, а
не доказательство готовности. Заполняется на конкретном аккаунте/домене.

состав — `manifest.json` (версия, commit_sha, дата сборки).

| Проверка | Ожидаемый результат | Факт |

## 2. Реальные интеграции (только после акта раздела 1)

| Проверка | Критерий | Факт |
|---|---|---|
| SMTP | письмо приходит на реальный ящик; `MAIL_MAILER=smtp` | |
| ЮKassa тестовый ключ | платёж → webhook → билет → возврат, без двойной выдачи | |
| Webhook | повтор и «не по порядку» не меняют итог | |
| Cron | `schedule:run` раз в минуту; heartbeat свежий (`get_cron_status`) | |
| Очередь | письма и вебхуки уходят, `failed_jobs` не растёт | |
| Бэкап | `backup:run --mode=full`, копия вне сервера | |
| Восстановление | дамп поднят на отдельной БД, сверка count/статусов; записать RTO/RPO | |
| Обновление | предыдущий релиз → актуальный через `/admin/updates`, данные целы | |
| MCP | токен из админки, `initialize` → `tools/list`, read-only tools работают | |
