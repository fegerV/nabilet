## ГЛАВНОЕ: «места не перемещаются» — настоящая первопричина
- В `HallEditorPage.vue` dragmove: `for (const [id] of seatDragIds)` — **деструктуризация по Set<string> давала ПЕРВЫЙ СИМВОЛ id** («t» из «table-…»). `seatDragBefore.get('t')` → undefined → тихий `continue`. Konva двигал узел визуально, модель НЕ менялась, watcher не срабатывал, автосейв не отправлялся, после перерисовки место «возвращалось». Исправлено на `for (const id of seatDragIds)` (два места: dragmove + finalizeSeatMove).
- Как искали: CDP-проба с stage-слушателями показала, что dragstart/dragmove/end узла срабатывают, но POST нет; добавили временные `console.warn('[drag-diag] …')` в обработчики и пересборку — «пишем target» не появлялся, `b` существовал, `target` не находился → деструктуризация. Осторожно: `Runtime.exceptionThrown` нужно ловить отдельно от consoleAPICalled; uncaught-исключений не было — баг был тихим.
- Эксперимент-подтверждение: стрелки-«nudge» (пишут `sectors.value` напрямую) автосейв триггерили, drag — нет.

## Второй баг: resolver рядов разворачивал кольца столов
- `finalizeSeatMove` «раздвигал коллизии» по X внутри «ряда»: у банкетного стола все места в row 1 по окружности с X-шагом < SEAT (16px) законно. Resolver шагом SEAT+GAP=22px разворачивал кольцо в линию (дельты 20,33,47,… — монотонные по X) и выносил места на соседние столы → 422. Также ломал дуги (крутые части дуги имеют X-шаг < SEAT). Теперь resolver+renumber только для `shape === 'grid'`; для `table` — skip целиком (круговую нумерацию не трогаем), наложение откатывается отдельной проверкой.

## Откаты вместо 422

## Инструментальные уроки
- Автосейв при ПЕРВОМ сохранении идёт на `POST /schema-versions` (создание черновика), а не `/schema-versions/draft` — фильтр по URL в CDP-скриптах должен быть шире (`schema-versions`), иначе «200» от GET-списка путает.
- Редактор в headless: персистентный профиль Chrome держит старый токен → 401 → logout чистит localStorage АСИНХРОННО, гард возвращает на главную; надёжная загрузка = свежий токен ПОСЛЕ старта + `Page.navigate` с cache-buster прямо на `/#/admin/halls/{pid}/editor` (reload перезагрузил бы главную).
