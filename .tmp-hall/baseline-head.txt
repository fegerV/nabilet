# Что это за файл.
#
# 344 находки PHPStan уровня 5, зафиксированные как ratchet: гейт падает только
# на НОВЫХ. Список может сокращаться, но не расти — это и есть смысл baseline.
#
# Почему 344, а не 1632. Из 1632 ошибок 1287 были `property.notFound` на
# Eloquent-моделях и JsonResource: колонки объявлены в миграциях, а не в PHP,
# поэтому анализатор их не видит. Лечится Larastan — но он требует
# `illuminate/console` не выше ^12, а проект на Laravel 13, и ни одна
# выпущенная версия не ставится. Вместо него в phpstan.neon объявлены
# universalObjectCratesClasses (Model, JsonResource) — это снимает 1287+163
# ложных срабатывания. Остальные 344 — не ложные, а следствия отсутствия
# Larastan: PHPStan не знает, что `Order::query()` возвращает Eloquent\Builder,
# что `$session->event()` — отношение, что `getReturnType()` вернёт
# ReflectionNamedType. Проверено выборочно: в рантайме все они работают.
#
# Как обновлять. Удаляйте записи, которые перестали воспроизводиться: PHPStan
# сам сообщает «Ignored error pattern … was not matched», и это падение, а не
# предупреждение — так мёртвые записи не накапливаются. Добавлять новые НЕЛЬЗЯ:
# если появилась ошибка, её чинят. Пересобрать файл целиком:
#   php vendor/bin/phpstan analyse --generate-baseline
