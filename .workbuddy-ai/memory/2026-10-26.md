## Batch 42 — refund-сумма: копия в RefundService вместо вызова RefundLedger (КОММИТ + ПУШ)
- Файлы: `app/Modules/Payments/Services/RefundService.php` (переписан `refund()`),
  `tests/Feature/Payments/PaymentWritePathTest.php` (+2 регр.-теста), `phpstan-baseline.neon` (−3 мёртвые записи).
- Коммит `9f3d5530`, пуш `61c73d27..9f3d5530 main -> main`.
- Дефект: `refund()` держал СВОИ 3 проверки суммы, дублирующие `RefundLedger::evaluate()`,
  а `evaluate()` звался НИЖЕ — его отказы были недостижимы. Правило «never refund more than
  was paid» работало только через копию.
- Решение: `refund()` делегирует решение `RefundLedger::evaluate()`, перевод причины в код

- Регрессия: переплата сверх остатка → 422 `REFUND_EXCEEDS_BALANCE` (код генерит только
  RefundLedger), частичный возврат → `partially_refunded`. Через `POST /payments/{id}/refund`
  с `amount` (роут валидирует `min:1`, поэтому нулевая сумма до RefundLedger не доходит — её
  ловит `PaymentSettlementTest`).
- phpstan: добавил `/** @var Payment $payment */` и `/** @var Refund $refund */` (create()
  возвращает крэйт `Model`, а не `Refund` из-за `universalObjectCratesClasses`). Убрал 3 мёртвые

## Batch 45 — символ валюты: копия в PDF билета вместо Money::symbolFor (КОММИТ + ПУШ)

  `app/Modules/Tickets/Services/TicketPdfRenderer.php` (import Money + делегат),
  `tests/Unit/CurrencySymbolSingleOwnerTest.php` (NEW, 2 метода).
- Коммит `021b1e9b`, пуш `e13ea1ae..021b1e9b main -> main`.
- Дефект: рендерер собирал `ticket.currency` через `$currency === 'RUB' ? '₽' : $currency`

- Регрессионный сторож: файл рендерера НЕ содержит ручной ветки `$currency==='RUB'?'₽'`
  и вызывает `Money::symbolFor()` (вернуть копию нельзя), плюс зафиксирована карта
  символов и вывод format() для RUB («50 000,00 ₽»).
