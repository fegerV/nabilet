# Руководство администратора по управлению контентом мероприятий в NABILET

## Обзор

Это руководство предназначено для администраторов системы NABILET и описывает работу с расширенным контентом мероприятий через **Vue-админку** (SPA на Vue 3 + TypeScript). Панель Filament из проекта удалена — все разделы администрирования живут в админке на Vue, данные она получает только через REST API (`/api/v1/*`).

## Вход и навигация в админ-панели

Вход: `/#/admin/login` (логин + пароль, токен Sanctum). Без токена любой путь `/admin/*`
редиректит на страницу входа. Интерфейс — левое меню (`AdminShell.vue`), группы разделов:

| Раздел | Путь в админке | API-эндпоинт | Назначение |
|--------|----------------|--------------|------------|
| **Дашборд** | `#/admin` | `GET /api/v1/events`, `/orders` | Сводка |
| **Мероприятия** | `#/admin/events` | `/api/v1/events` | Список, фильтр по статусу, поиск |
| **Форма мероприятия** | `#/admin/events/new`, `#/admin/events/:id` | `POST/PATCH/PUT /api/v1/events…` | Создание/редактирование, включая расширенный контент |
| **Сеансы** | `#/admin/sessions` | `/api/v1/sessions` | CRUD сеансов |
| **Площадки** | `#/admin/venues` | `/api/v1/venues` | CRUD площадок |
| **Залы** | `#/admin/halls` | `/api/v1/halls` | Список залов + конструктор схем (Hall Editor) |
| **Заказы** | `#/admin/orders` | `/api/v1/orders` | Список, деталка, отмена |

Спикеры, спонсоры, FAQ, артисты и расписание — это секции внутри формы мероприятия
(`AdminEventFormPage.vue`); они сохраняются вместе с событием одним запросом к API.

### Права доступа

Роли проверяются на бэкенде (middleware `EnsureAdminRole`, роли из таблицы `user_roles`):

| Роль | Чтение | Создание / редактирование | Удаление |
|------|--------|---------------------------|----------|
| admin | ✅ | ✅ | ✅ |
| manager | ✅ | ✅ | ✅ |
| support | ✅ (ограниченно) | ❌ (403) | ❌ (403) |
| аноним | только публичные GET | ❌ (401) | ❌ (401) |

## Управление спикерами

### Добавление нового спикера

1. Откройте **Мероприятия → нужное мероприятие** (`#/admin/events/:id`)
2. В секции **«Спикеры»** нажмите **«Добавить спикера»**
3. Заполните форму:

#### Обязательные поля:
- **Имя (name)** — полное имя спикера

#### Рекомендуемые поля:
- **Должность/компания (position, company)**
- **Фото (avatar)** — фотография спикера (400×400px)
- **Биография (bio)** — развёрнутая биография

#### Дополнительные настройки:
- **Главный спикер (is_featured)** — выделение спикера
- **Порядок (sort_order)** — порядок отображения
- **Соцсети (social_links)** — пары «платформа → ссылка/ник»

## Лучшие практики

### Рекомендации

1. **Согласованность**: Единый стиль имён спикеров
2. **Изображения**: PNG/JPG, макс. 2MB
3. **Порядок**: Featured (0-10), обычные (100+)
4. **Slug**: задавайте читаемый slug при создании — по нему работают SEO-страницы (`/event/{slug}`)

## Частые вопросы

### Как скопировать спикера?
Нажмите «Дублировать» в строке списка секции «Спикеры» (копирует поля в новую запись).

### Почему спикер не виден?
Проверьте: активность записи (sort_order/is_featured), статус мероприятия, кэш витрины.

### Как изменить порядок?
Измените `sort_order` (меньше = выше) или перетащите строку в списке.

### Ошибки при сохранении формы?
API отвечает в формате `{error: {code, message, errors?}}`; 409 — конфликт (например, занятый slug), 403 — не хватает роли.
