# Инструкция по запуску тестов

## Требования

- Node.js 20+
- npm 10+

## Установка зависимостей

```bash
npm install
```

## Запуск тестов

### Однократный запуск
```bash
npm test
```

### Режим наблюдения (автоматический перезапуск при изменениях)
```bash
npm run test:watch
```

## Структура тестов

Тесты находятся в директории `tests/Unit/Components/`:

- `HallEditor.test.js` - тесты компонента редактора схем залов

## CI/CD интеграция

Для использования в CI/CD добавьте шаг:

```yaml
- name: Install dependencies
  run: npm install

- name: Run tests
  run: npm test
```

## Добавление новых тестов

1. Создайте новый файл теста в `tests/Unit/Components/`
2. Используйте структуру существующих тестов
3. Добавьте тесты для новой функциональности
4. Запустите `npm test` для проверки

## Пример добавления теста

```javascript
describe('Новая функция', () => {
  it('должен делать что-то', () => {
    const result = wrapper.vm.newFunction();
    expect(result).toBe(expectedValue);
  });
});
```

## Troubleshooting

### Ошибка "Failed to load PostCSS config"
Убедитесь, что `postcss.config.js` использует ES module syntax:
```javascript
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

### Ошибка импорта компонентов
Проверьте правильный путь к компоненту:
```javascript
import HallEditor from '../../../resources/js/components/HallEditor.vue';
```

### Проблемы с окружением jsdom
Убедитесь, что в `vite.config.js` указано:
```javascript
test: {
  environment: 'jsdom',
  globals: true,
}
```
